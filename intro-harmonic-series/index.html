A short recap

The harmonic series, back in one view.

You have already encountered the harmonic series in class. This is a quick reset before we go deeper: what the fundamental is, how partial frequencies relate, and where the first eight partials land musically.

Reconnect the sound, the frequency, and the note.

Move through the overview in order, then use the listening examples to refresh the interval landmarks: octave, fifth, third, seventh, and octave again.

01 / vibrationReconnect with the source of the series.

Start with a fundamental.

The fundamental is the pitch we hear as the main reference for a sound. Every harmonic series begins there. We will use C2 as a concrete example for listening, but the same pattern starts from any fundamental.

C2 is the example fundamental
02 / frequenciesOne simple number pattern explains every partial.

Partials are whole-number multiples of the fundamental frequency.

Hertz (Hz) means vibrations per second. To keep the arithmetic easy, imagine a fundamental of 100 Hz. The second partial is 200 Hz, the third is 300 Hz, and the pattern keeps going.

100 Hz frequency map

partial number × 100 Hz

This is a clean math example, not the C2 example above. A real C2 fundamental is about 65.41 Hz, so its partials are multiples of 65.41 instead.

03 / intervalsThe first eight partials become musical notes.

Now give the partials note names.

Once a fundamental note is given to you, the early harmonic series creates a familiar path upward. Starting from C2, these are the first eight partials. Tap any card to hear that partial; “from previous” describes the move from the note immediately before it.

There are more harmonics after the eighth partial. For Principles of Music Technology, this overview focuses on the first eight.
